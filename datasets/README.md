# datasets

The notebook reads six CSV files from this folder. They come with the Global Career Accelerator program and are not published in this repo.

| File | Used in | What it holds |
|---|---|---|
| `grammy_live_web_analytics.csv` | Tasks 2 to 7 | Daily traffic for grammy.com from 2017: visitors, pageviews, sessions, bounced sessions, average session length, and flags for awards week and awards night. Before 2022-02-01 this is the combined site. |
| `ra_live_web_analytics.csv` | Tasks 2 to 7 | The same daily metrics for recordingacademy.com, starting 2022-02-01. |
| `grammys_age_demographics.csv` | Task 8 | Share of grammy.com visitors in each age group. |
| `tra_age_demographics.csv` | Task 8 | Share of recordingacademy.com visitors in each age group. |
| `desktop_users.csv` | LevelUp | Daily desktop visitors to grammy.com. |
| `mobile_users.csv` | LevelUp | Daily mobile visitors to grammy.com. |
