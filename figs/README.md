# figs

The LevelUp section of the notebook displays `figs/TheAMAs.png`. It is a screenshot of a web analytics dashboard for the American Music Awards website (April to June 2023), provided by the Global Career Accelerator program.

The image is not included in this repo, so it shows as a broken image when the notebook is viewed on GitHub. The figures the analysis uses from it (visit duration, pages per visit and bounce rate) are written out in the text of the same notebook cell.
